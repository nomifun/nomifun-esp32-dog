# 硬件设计

| 文件 | 说明 |
|---|---|
| `robot-dog-sch-pcb.eprj2` | 嘉立创 EDA 专业版（EasyEDA Pro）工程，包含原理图与 PCB |

工程中有两版设计：v1 为模块化原型，v4 为贴片版主板。本仓库固件对应 v4，它带有 SD 卡、充电检测、4 个按键和 WS2812 灯带接口。
v1 的第二路灯带（`LEDC_RIGHT_G38`）在 v4 中已经移除。引脚和网络名见 [docs/dog/hardware.md](../docs/dog/hardware.md)。

## 主要外购件

元器件清单可以在 EDA 中导出。整机组装还需要：

- SG90 180° 舵机 × 4
- 103450 锂电池
- 3070 腔体喇叭
- 1.3 英寸 SH1106 OLED（引脚顺序以 GND 开头）
- microSD 卡
- WS2812 灯带与按键小板
