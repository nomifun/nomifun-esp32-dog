# 按键与菜单

屏幕为 128×64 单色 OLED，各级菜单都是左右切换：顶部显示类别和页码，左侧是 24×24 像素图标，右侧带框区域显示当前选项，
框下方一行显示状态或说明。过长的状态或曲名会单行滚动。菜单字体在联网前加载，配网状态下也能完整显示中文。

## 按键

| 操作 | 功能 |
|---|---|
| 键 1 单击 / 键 3 单击 | 下一项 / 上一项；待机时按任一键进入应用菜单 |
| 键 2 单击 | 确认 |
| 键 2 长按（约 0.65 秒） | 返回上级，返回后保留之前选中的位置 |
| BOOT 单击 | 回到聊天画面并切换对话；本地音乐正在播放或等待播放时，停止或取消音乐 |
| BOOT 长按 5 秒后松开 | 清除连接配置并重启进入配网（保留舵机校准和 SD 卡文件） |
| 键 2 双击 / 键 3 双击 | 播放音乐且不在菜单中时，切换到下一首 |
| 按住键 1 再双击键 3 | 舵机测试：执行一次摇摆动作 |

- 音量页：键 1 / 键 3 每次加减 5%；长按可连续调节，松开或离开音量页后停止。按键 2 直接返回设置，屏幕会提示“中键返回”。
- 设置、表情、音乐、闹钟、关于等页面：切到最后的“返回上级”，按键 2 回到应用菜单。
- 应用菜单：切到最后的“退出菜单”，按键 2 回到聊天画面，不会开启或切换对话。

## 页面

| 应用 | 用途 |
|---|---|
| 聊天 | 进入聊天。服务就绪时幂等唤醒对话，不会关闭正在进行的会话；后台字幕不会抢占菜单 |
| 表情 | 选择并显示 21 种内置表情 |
| 音乐 | 播放/停止、上一首、下一首、停止播放；底部显示当前歌曲或失败原因 |
| 闹钟 | 查看时间和歌曲；只有“闹钟开关”可以确认切换，其他字段确认后提示“仅供查看” |
| 设置 | 音量、开机动画、充电灯效、自由探索、重新配网 |
| 关于 | 逐页查看固件版本、网络地址、设备型号 |

## 音乐与闹钟

- 音乐文件放在 SD 卡的 `music/mp3` 目录，使用 MP3 格式。
- “播放/停止”可以停止播放或取消待播。停止后再次确认，会从当前歌曲开头重播；如果当前歌曲失效或尚未选曲，则播放第一首有效歌曲。
- 用“下一首 / 上一首”主动换曲。
- 闹钟的日期、时间和歌曲通过语音（MCP 工具 `self.alarm.set_alarm`）设置，屏幕只用于查看和开关。日期闹钟需要正确同步系统时间。

## 重新配网

除了 BOOT 长按，也可以在“设置 → 重新配网”中操作。框内默认选中“取消”，下方的“说明：保留网络”只是说明文字；
必须主动切到框内的“清除重启”并确认才会执行。

## 当前限制

- 不支持 SD 卡录音、断点暂停/恢复播放、SD 卡热插拔、在屏幕上编辑闹钟，也不支持自定义唤醒词。
- 麦克风与唤醒效果、声学表现、步态、电池曲线、灯效和充电检测请以实机表现为准。
